Когда использовать деанонимизацию из буфера

Деанонимизация из буфера обмена удобна, когда у вас есть анонимизированный текст в любом месте:

  • ответ ИИ в браузере;
  • текст из другого редактора;
  • фрагмент из электронной почты и т.п.

Важно только, чтобы в тексте использовались псевдонимы в квадратных скобках, совместимые с вашим словарём pseudos.json.

Порядок действий

  1. Выделите анонимизированный текст в исходной программе.
  2. Скопируйте его в буфер обмена (обычно Ctrl+C).
  3. Перейдите в окно «Анонимизатора».
  4. Нажмите кнопку «Деанонимизировать из буфера».
  5. Дождитесь сообщения об успешной деанонимизации.
  6. Перейдите в программу, где вам нужен результат, и вставьте текст из буфера (обычно Ctrl+V).

Возможные сообщения об ошибках

  • «Буфер обмена пуст». В буфере нет текста. Скопируйте текст ещё раз и повторите попытку.
  • Ошибка чтения буфера обмена. Может возникнуть при проблемах с доступом к буферу (например, из-за ограничений безопасности). Попробуйте закрыть лишние программы и повторить запрос.

Как выполняется деанонимизация

Внутри программа:

  • считывает текст из буфера обмена;
  • составляет упорядоченный список замен вида [ПСЕВДОНИМ] → исходный текст;
  • последовательно применяет все замены, начиная с самых длинных шаблонов;
  • записывает результат обратно в буфер обмена.

При этом исходный анонимизированный текст нигде не сохраняется, что дополнительно уменьшает риск утечки данных.
