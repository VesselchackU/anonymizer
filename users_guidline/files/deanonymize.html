Общий принцип работы

Деанонимизация файлов выполняет обратную операцию: вместо псевдонимов вида [ПСЕВДОНИМ] программа подставляет исходные строки из словаря.

Результат деанонимизации не сохраняется в новый файл, а помещается в буфер обмена. Далее вы можете вставить текст в любую программу.

Порядок действий

  1. Убедитесь, что файл pseudos.json содержит актуальный словарь для данного документа.
  2. На главном окне нажмите кнопку «Деанонимизировать в буфер».
  3. Выберите файл, содержащий анонимизированный текст.
  4. Дождитесь сообщения об успешной деанонимизации.
  5. Откройте нужную программу (Word, блокнот и т.п.) и вставьте текст из буфера обмена.

Деанонимизация текстовых файлов (.txt)

Для файлов .txt программа:

  • читает содержимое файла (UTF-8, при необходимости — Windows-1251);
  • составляет список пар вида [ПСЕВДОНИМ] → исходный текст;
  • сортирует их по длине шаблона от длинных к коротким;
  • последовательно заменяет все вхождения псевдонимов на исходный текст;
  • помещает результат в буфер обмена.

Деанонимизация документов Word (.docx)

Для файлов .docx программа:

  • открывает документ;
  • извлекает текст из абзацев и таблиц;
  • извлекает текст из колонтитулов (верхних и нижних), включая таблицы;
  • выполняет замены [ПСЕВДОНИМ] → исходный текст в собранном тексте;
  • формирует результирующую текстовую строку и копирует её в буфер обмена.

Таким образом, результат деанонимизации для .docx — это текст, который вы вставляете туда, где он вам нужен (например, в новый документ Word).

Деанонимизация документов .doc

Для файлов .doc программа использует компонент textract для извлечения текста. После этого:

  • все вхождения псевдонимов вида [ПСЕВДОНИМ] заменяются на исходные строки;
  • полученный текст копируется в буфер обмена.

При отсутствии textract программа сообщает, что поддержка .doc недоступна и рекомендует конвертировать файл в .docx.

Особенности и ограничения

  • Деанонимизация срабатывает только для точных совпадений вида [ПСЕВДОНИМ].
  • Если в ответе ИИ были изменены скобки или содержимое внутри них, такая метка может не восстановиться.
  • Исходный файл при деанонимизации не изменяется.
  • Результат всегда нужно вставлять вручную из буфера обмена в нужную программу.
