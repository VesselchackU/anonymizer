Поддерживаемые форматы

Программа умеет анонимизировать файлы следующих типов:

  • .txt – обычные текстовые файлы;
  • .docx – документы Microsoft Word нового формата;
  • .doc – документы Microsoft Word старого формата (при наличии дополнительной библиотеки).

Для файлов .doc используется внешняя библиотека. Если она не установлена, программа покажет сообщение, что поддержка формата требует установки дополнительного компонента или предварительной конвертации в .docx.

Как выбрать файл для анонимизации

Шаги

  1. Откройте программу Анонимизатор.
  2. Убедитесь, что нужные пары «исходный текст → псевдоним» уже добавлены в словарь (см. раздел «Словарь псевдонимов»).
  3. В блоке «Операции» нажмите кнопку «Анонимизировать файл».
  4. Откроется стандартное окно выбора файла:
    • по умолчанию будет открыт последний каталог, в котором Вы выбирали файл ранее;
    • в списке типов файлов можно выбрать «Поддерживаемые файлы» или «Все файлы».
  5. Выберите нужный файл и нажмите «Открыть».

Если Вы закроете окно выбора файла, не выбрав документ, анонимизация просто не начнётся.

Что происходит при анонимизации

После выбора файла программа выполняет следующие действия:

  1. Составляет упорядоченный список замен из словаря:
    • все пары «исходный текст → псевдоним» сортируются по длине исходного текста – от более длинных к более коротким;
    • это позволяет корректно обрабатывать случаи, когда один фрагмент входит в другой.
  2. В зависимости от типа файла:
    • для .txt:
      • файл читается в кодировке UTF-8, при неудаче – в Windows-1251;
      • поочерёдно заменяются все вхождения исходных текстов на псевдонимы в формате [ПСЕВДОНИМ];
      • создаётся новый файл с анонимизированным содержимым.
    • для .docx:
      • программа обрабатывает весь документ: обычный текст, содержимое таблиц, а также верхние и нижние колонтитулы;
      • во всех этих местах исходные тексты заменяются на [ПСЕВДОНИМ];
      • создаётся новый документ .docx с анонимизированным содержимым.
    • для .doc:
      • при наличии поддержки формат читается во внутренний текст;
      • в тексте выполняются замены по словарю;
      • результат сохраняется в новый текстовый файл формата .txt.
  3. После завершения операции программа показывает окно с сообщением о том, под каким именем сохранён результат.

Имена создаваемых файлов

Анонимизированный файл всегда создаётся рядом с исходным, в том же каталоге. К имени добавляется суффикс «_аноним».

Примеры:

  • отчет.docx → отчет_аноним.docx
  • доклад.txt → доклад_аноним.txt

Если файл с таким именем уже существует, программа добавляет номер:

  • отчет_аноним.docx уже есть → создаётся отчет_аноним001.docx;
  • если и он существует – отчет_аноним002.docx и т.д.

Особенности и ограничения

  • Замены регистрозависимые: Иванов и иванов – разные строки.
  • Если словарь пуст, анонимизация пройдёт без изменений содержимого файла.
  • При ошибке чтения файла (например, из-за неподдерживаемого формата или проблем с кодировкой) программа покажет сообщение об ошибке.
  • Исходный файл не изменяется – создаётся новый файл с анонимизированным содержимым.
