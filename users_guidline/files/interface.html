Общие элементы окна

После запуска программы открывается главное окно «Анонимизатор текстов». Оно состоит из трёх основных блоков:

  1. «Добавление псевдонима» – слева сверху.
  2. «Операции» – слева снизу.
  3. «Список псевдонимов» – справа.

Блок «Добавление псевдонима»

Этот блок используется для пополнения словаря замен – добавления новых пар «исходный текст → псевдоним».

  • Поле «Анонимизировать» – сюда вводится исходный текст, который нужно скрыть (например, фамилия, название компании и т.п.).
  • Поле «Псевдоним» – сюда можно ввести желаемое обозначение вместо исходного текста (например, ИСТЕЦ1 или ОРГАНИЗАЦИЯ_A). Это поле можно оставить пустым – тогда псевдоним будет создан автоматически.
  • Кнопка «Добавить» – сохраняет введённую пару в словарь.

Кнопка «Добавить» становится активной только тогда, когда в поле «Анонимизировать» есть непустой текст.

Пошаговое добавление пары

  1. Щёлкните мышью в поле «Анонимизировать».
  2. Введите текст, который нужно скрыть (например, Иванов).
  3. При желании щёлкните в поле «Псевдоним» и введите собственный вариант (например, ИСТЕЦ1). Если оставить поле пустым, программа сама подберёт псевдоним.
  4. Нажмите кнопку «Добавить».
  5. Пара будет сохранена в словарь и появится в списке справа.

Блок «Операции»

В этом блоке находятся три основные кнопки работы с файлами и буфером обмена:

  • «Анонимизировать файл» – открывает диалог выбора файла и выполняет анонимизацию. Подробно описано в разделе «Анонимизация файлов».
  • «Деанонимизировать в буфер» – деанонимизирует выбранный файл и помещает восстановленный текст в буфер обмена. См. раздел «Деанонимизация файлов».
  • «Деанонимизировать из буфера» – деанонимизирует текст, который уже находится в буфере обмена. См. раздел «Деанонимизация текста из буфера обмена».

Во время выполнения операций программа временно блокирует эти кнопки и показывает «часики» вместо курсора. После завершения операции кнопки снова становятся активными.

Блок «Список псевдонимов»

Правая часть окна – это список всех ключей (исходных текстов), внесённых в словарь.

  • Список – отображает все исходные тексты, отсортированные строго по алфавиту. В каждый момент времени можно выбрать только один элемент.
  • Поле «Псевдоним» (под списком) – показывает псевдоним, соответствующий выбранному в списке исходному тексту. Поле только для чтения.
  • Кнопка «Удалить» – удаляет выбранную пару из словаря после подтверждения.

Просмотр и удаление записи

  1. Выберите нужный элемент в списке слева кликом мыши.
  2. В поле «Псевдоним» ниже отобразится соответствующий ему псевдоним.
  3. Чтобы удалить пару, нажмите кнопку «Удалить».
  4. Подтвердите удаление в появившемся диалоговом окне.

После добавления или удаления пар словарь автоматически сохраняется в файл pseudos.json, а список в правой части окна обновляется.
