Назначение файла main.ini

Файл main.ini – это файл настроек программы. В нём сохраняются:

  • положение окна на экране;
  • последний каталог, из которого открывался файл.

Благодаря этому программа «запоминает» Ваши предпочтения и при следующем запуске восстанавливает удобную конфигурацию.

Координаты окна

При закрытии и перемещении окна программа сохраняет его координаты:

  • coord_x – положение окна по горизонтали;
  • coord_y – положение окна по вертикали.

При следующем запуске программа пытается открыть окно на тех же координатах. Если координаты отсутствуют или некорректны, окно будет отображено по центру экрана.

Последний каталог открытия файла

В файле main.ini также хранится информация о каталоге, из которого Вы последний раз открывали файл:

  • last_open_dir – путь к каталогу, который по умолчанию открывается в диалоге выбора файла.

Каждый раз, когда Вы успешно выбираете файл для анонимизации или деанонимизации, программа обновляет значение last_open_dir на каталог выбранного файла.

Это экономит время, если Вы регулярно работаете с документами из одной и той же папки.

Где находится main.ini

По умолчанию файл main.ini находится в той же папке, что и основной исполняемый файл программы. В некоторых случаях разработчик может настроить другое расположение (например, через переменные окружения). Для обычного пользователя это обычно не требуется.

Рекомендации по изменению настроек

  • Обычно нет необходимости вручную редактировать main.ini. Программа автоматически поддерживает его в актуальном состоянии.
  • Если окно стало появляться вне видимой области (например, вследствие смены мониторов), можно:
    • закрыть программу;
    • удалить или переименовать файл main.ini;
    • запустить программу снова – будут созданы настройки по умолчанию, и окно появится в стандартном месте.
