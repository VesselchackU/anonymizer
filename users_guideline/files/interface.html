Общий вид окна

Главное окно программы состоит из трёх основных областей:

  • «Добавление псевдонима» (слева сверху) — ввод новых замен.
  • «Операции» (слева снизу) — работа с файлами и буфером обмена.
  • «Список псевдонимов» (справа) — просмотр и удаление существующих замен.

Блок «Добавление псевдонима»

Этот блок находится в верхней левой части окна и оформлен как группа с заголовком «Добавление псевдонима».

  • Поле «Анонимизировать». Однострочное поле ввода, где вы указываете текст, который нужно скрыть. Это может быть фамилия, часть фамилии, название организации и т.п.
  • Поле «Псевдоним». Необязательное поле для ввода желаемого псевдонима. Если оставить его пустым, программа сгенерирует псевдоним автоматически.
  • Кнопка «Добавить». Становится активной, когда в поле «Анонимизировать» есть непустой текст. После нажатия пара «исходный текст → псевдоним» добавляется в словарь и отображается в списке псевдонимов.

Если вы пытаетесь добавить пустой ключ или ключ, который уже существует в словаре, программа покажет предупреждение и не добавит запись.

Блок «Операции»

В нижней левой части окна находится блок «Операции» с тремя кнопками:

  • «Анонимизировать файл». Открывает диалог выбора файла. После выбора программа создаёт анонимизированную копию документа.
  • «Деанонимизировать в буфер». Открывает диалог выбора файла и выполняет деанонимизацию текста в нём. Результат помещается в буфер обмена.
  • «Деанонимизировать из буфера». Берёт текст из буфера обмена, выполняет деанонимизацию и возвращает результат обратно в буфер обмена.

Во время длительных операций (например, при обработке большого документа) кнопки становятся неактивными, а курсор меняется на «часики». После завершения обработки состояние интерфейса восстанавливается.

Блок «Список псевдонимов»

Правая часть окна — это блок «Список псевдонимов», состоящий из:

  • Списка псевдонимов. Здесь отображаются все ключи (исходные строки) из словаря, отсортированные по алфавиту. Выбор в списке одиночный.
  • Поле «Псевдоним» под списком. Показывает псевдоним, соответствующий выбранному в списке ключу. Поле только для чтения.
  • Кнопка «Удалить». Удаляет выбранную пару «ключ → псевдоним» из словаря (после подтверждения).

Удаление записи сразу сохраняется в словаре псевдонимов. При следующем запуске программы изменения сохранятся.
