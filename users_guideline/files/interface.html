Общий вид окна

Главное окно программы состоит из следующих элементов:

  • Верхняя строка меню с пунктами «Файл», «Псевдонимы» и «Помощь».
  • Блок «Добавление псевдонима» (слева сверху) — ввод новых пар «исходный текст → псевдоним».
  • Блок «Операции» (слева снизу) — анонимизация и деанонимизация файлов и буфера обмена.
  • Блок «Список псевдонимов» (справа) — просмотр и удаление существующих записей.

Главное меню

Все основные действия доступны не только через кнопки на форме, но и через верхнее меню. Это удобно, если вы привыкли работать с клавиатурой или окно сильно уменьшено по ширине.

Меню «Файл»

  • «Анонимизировать файл...»
    Открывает диалог выбора файла и запускает анонимизацию. Полный аналог кнопки «Анонимизировать файл» в блоке «Операции».
  • «Деанонимизировать файл → файл...»
    Деанонимизирует выбранный файл и создаёт новый файл с суффиксом _деанон. Соответствует кнопке «Деанон файл → файл» в блоке «Операции».
  • «Деанонимизировать файл → буфер...»
    Деанонимизирует выбранный файл и помещает результат в буфер обмена. Аналог кнопки «Деанон файл → буфер».
  • «Деанонимизировать буфер → буфер»
    Берёт текст из буфера обмена, деанонимизирует его и записывает результат обратно в буфер. Полный аналог кнопки «Деанон буфер → буфер».

Меню «Псевдонимы»

  • «Новый файл псевдонимов...»
    Создаёт новый пустой файл словаря .json. Все текущие пары в памяти очищаются, и этот файл становится активным. После этого любые новые записи будут сохраняться именно в него.
  • «Открыть файл псевдонимов...»
    Открывает существующий файл словаря .json. Содержимое словаря загружается, список псевдонимов обновляется, а выбранный файл становится активным.
  • «Сохранить файл псевдонимов как...»
    Сохраняет текущий словарь в новый файл .json. После сохранения именно этот новый файл становится активным. Удобно для ветвления словарей по проектам.

Меню «Помощь»

  • «О программе...»
    Открывает модальное окно с краткой информацией о приложении: название, версия, назначение, сведения об авторе и кликабельная ссылка на репозиторий с кодом.
  • «Справка (руководство пользователя)»
    Открывает HTML-руководство пользователя в браузере. Используется файл index.html из каталога users_guideline.

Блок «Добавление псевдонима»

Этот блок расположен в верхней левой части окна и оформлен как рамка с заголовком «Добавление псевдонима».

  • Поле «Анонимизировать».
    Однострочное поле, где указывается текст, который нужно скрыть: фамилия, часть фамилии, название организации, фрагмент адреса и т.п. Без непустого значения добавить запись нельзя.
  • Поле «Псевдоним».
    Необязательное поле. Если оставить его пустым, программа сгенерирует псевдоним автоматически. Можно задавать и свои обозначения, например ФИО001, ОРГ001.
  • Кнопка «Добавить».
    Активна только если в поле «Анонимизировать» есть непустой текст. При нажатии:
    • проверяется, что такого ключа ещё нет в словаре;
    • при необходимости генерируется уникальный псевдоним;
    • новая пара добавляется в активный файл словаря;
    • список псевдонимов справа обновляется.

При попытке добавить пустой ключ или уже существующий будет показано предупреждение, а запись не создастся.

Блок «Операции»

В нижней левой части окна находится блок «Операции». Здесь расположены четыре кнопки:

  • «Анонимизировать файл».
    Запускает анонимизацию выбранного файла и создаёт новый файл с суффиксом _аноним. Подробности см. в разделе «Анонимизация файлов».
  • «Деанон файл → буфер».
    Деанонимизирует файл и копирует результат в буфер обмена. Описание см. в разделе «Деанонимизация файлов».
  • «Деанон файл → файл».
    Деанонимизирует файл и создаёт новый файл с суффиксом _деанон. Исходный документ при этом не изменяется.
  • «Деанон буфер → буфер».
    Берёт текст из буфера обмена, деанонимизирует его и возвращает результат обратно в буфер. См. раздел «Деанонимизация из буфера».

Эти кнопки полностью дублируются соответствующими пунктами меню «Файл», поэтому можно пользоваться тем, что привычнее.

Блок «Список псевдонимов»

Правая часть окна — блок «Список псевдонимов». Здесь отображается содержимое активного файла словаря.

  • Список ключей.
    Основная часть блока — список исходных строк (ключей словаря), отсортированных по алфавиту. Выбор в списке одиночный.
  • Поле «Псевдоним» под списком.
    Отображает псевдоним, соответствующий выбранному ключу. Поле только для чтения.
  • Кнопка «Удалить».
    Удаляет выбранную пару «ключ → псевдоним» после подтверждения. Изменения сразу сохраняются в активном файле словаря.

При переключении на другой файл словаря через меню «Псевдонимы» список автоматически обновляется и показывает данные из нового активного файла.

Окно «О программе»

Окно «О программе...» открывается через меню «Помощь» → «О программе...».

Оно представляет собой небольшое модальное окно с:

  • названием приложения и номером версии;
  • кратким описанием назначения программы;
  • информацией об авторе;
  • кликабельной ссылкой на репозиторий с кодом приложения;
  • кнопкой «Закрыть» для выхода из окна.

Пока окно «О программе» открыто, основное окно недоступно для ввода — это стандартное модальное поведение.

Поведение интерфейса при длительных операциях

При анонимизации и деанонимизации файлов обработка выполняется в отдельном потоке. Графический интерфейс при этом не «подвисает», но на время работы:

  • курсор меняется на «часики»;
  • кнопки блока «Операции» и кнопка «Добавить» временно блокируются;
  • по завершении операции выводится сообщение об успехе или об ошибке, а состояние интерфейса восстанавливается.

При деанонимизации текста из буфера обмена действует аналогичный принцип: пока идёт обработка, кнопки операций отключены, а затем автоматически возвращаются в нормальное состояние.
