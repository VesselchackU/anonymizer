Поддерживаемые форматы файлов

Для анонимизации поддерживаются следующие форматы:

  • Текстовые файлы .txt;
  • Документы Word .docx;
  • Документы Word старого формата .doc (при наличии установленного компонента textract).

Общий порядок анонимизации

  1. Убедитесь, что активный файл словаря содержит нужные пары «исходный текст → псевдоним».
  2. Выберите один из способов запуска операции:
    • нажмите кнопку «Анонимизировать файл» в блоке «Операции»;
    • или откройте меню «Файл» → «Анонимизировать файл...».
  3. В открывшемся диалоге выберите файл для анонимизации.
  4. Дождитесь сообщения о результате с указанием имени нового файла.

Работа с текстовыми файлами (.txt)

Для файлов .txt программа:

  • пытается прочитать файл в кодировке UTF-8;
  • если это не удаётся, повторяет попытку в Windows-1251;
  • последовательно заменяет исходные строки на псевдонимы в квадратных скобках ([ПСЕВДОНИМ]);
  • создаёт новый файл в той же папке с суффиксом _аноним.

Пример: из файла отчёт.txt будет получен отчёт_аноним.txt.

Работа с документами Word (.docx)

Для файлов .docx программа:

  • открывает документ как файл Word;
  • выполняет замены в основном тексте (абзацы документа);
  • выполняет замены во всех таблицах (во всех ячейках);
  • выполняет замены в колонтитулах (верхних и нижних), включая таблицы в колонтитулах;
  • сохраняет результат в новый файл в том же каталоге с суффиксом _аноним и расширением .docx.

Пример: из файла договор.docx будет создан договор_аноним.docx.

Работа с документами .doc

Для документов старого формата .doc программа использует дополнительный компонент textract для извлечения текста.

При наличии textract:

  • текст извлекается из файла .doc;
  • последовательно выполняются замены исходных строк на [ПСЕВДОНИМ];
  • результат сохраняется в новый текстовый файл .txt с суффиксом _аноним.

Пример: из файла отчёт.doc будет получен отчёт_аноним.txt.

Если компонент textract не установлен, программа сообщит, что поддержка .doc недоступна, и предложит предварительно конвертировать файл в формат .docx.

Суффиксы и нумерация имён файлов

При создании нового файла для анонимизированного текста используется суффикс _аноним. Если файл с таким именем уже существует, программа добавляет номер:

  • документ_аноним.docx;
  • документ_аноним001.docx;
  • документ_аноним002.docx и т.д.

Исходный файл при этом не изменяется, создаётся только новая версия.

Типичные ошибки при анонимизации

  • «Не удалось открыть файл как документ Word».
    Возможные причины:
    • файл .docx открыт в другой программе и ещё не полностью сохранён;
    • файл был удалён, переименован или перемещён;
    • файл повреждён и не читается как корректный документ Word.
    Проверьте файл, закройте его во всех программах и повторите попытку.
  • Ошибка чтения текстового файла.
    Может возникнуть, если файл закодирован экзотической кодировкой или повреждён. В таком случае попробуйте открыть его в текстовом редакторе и сохранить в простой кодировке (UTF-8 без BOM).
  • Ничего не изменилось.
    Проверьте, что:
    • вы открыли именно _аноним-версию файла;
    • активный файл словаря соответствует этому документу;
    • нужные строки действительно присутствуют в словаре с учётом регистра.
