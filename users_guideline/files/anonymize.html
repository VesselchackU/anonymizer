Поддерживаемые форматы файлов

Для анонимизации поддерживаются следующие форматы:

  • Текстовые файлы .txt;
  • Документы Word .docx;
  • Документы Word старого формата .doc (при наличии установленного компонента textract).

Общий порядок анонимизации

  1. Убедитесь, что необходимые пары «исходный текст → псевдоним» уже добавлены в словарь.
  2. Нажмите кнопку «Анонимизировать файл» в блоке «Операции».
  3. В открывшемся диалоге выберите нужный файл.
  4. Дождитесь сообщения об успешном завершении операции с указанием имени нового файла.

Работа с текстовыми файлами (.txt)

Для файлов .txt программа:

  • читает содержимое файла (сначала в кодировке UTF-8, при необходимости — в Windows-1251);
  • последовательно заменяет все вхождения исходных строк на соответствующие псевдонимы в квадратных скобках ([ПСЕВДОНИМ]);
  • создаёт новый файл в той же папке с суффиксом _аноним.

Пример: из файла отчёт.txt будет получен отчёт_аноним.txt.

Работа с документами Word (.docx)

Для файлов .docx программа:

  • открывает документ как файл Word;
  • выполняет замены во всех основных абзацах;
  • выполняет замены в таблицах (во всех ячейках);
  • выполняет замены в колонтитулах (верхних и нижних) и связанных с ними таблицах;
  • сохраняет результат в новый файл с суффиксом _аноним в формате .docx.

Пример: из файла договор.docx будет создан договор_аноним.docx.

Работа с документами .doc

Для документов старого формата .doc программа использует дополнительный компонент textract, чтобы извлечь текст.

При наличии textract:

  • текст извлекается из файла .doc;
  • выполняются все замены исходных строк на [ПСЕВДОНИМ];
  • результат сохраняется в новый текстовый файл .txt с суффиксом _аноним.

Пример: из файла отчёт.doc будет получен отчёт_аноним.txt.

Если компонент textract не установлен, программа выдаст сообщение о том, что поддержка .doc недоступна и предложит конвертировать файл в формат .docx.

Суффиксы и нумерация имён файлов

При создании нового файла используется суффикс _аноним. Если в папке уже существует файл с таким именем, программа добавляет к суффиксу номер:

  • документ_аноним.docx;
  • документ_аноним001.docx;
  • документ_аноним002.docx и т.д.

Исходный файл при этом не изменяется, создаётся только новая версия.
