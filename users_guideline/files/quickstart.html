Быстрый старт

Этот раздел рассчитан на пользователя, который хочет не разбираться в теории, а быстро получить рабочий результат: анонимизировать файл, отправить его в ИИ и вернуть обратно нормальный текст.

Вариант 1. Познакомиться на тестовом примере

  1. Запустите программу.
  2. В меню выберите «Псевдонимы» → «Открыть файл псевдонимов...» и укажите файл pseudos_three_musketeers.json из каталога с внутренними файлами программы.
  3. Нажмите кнопку «Анонимизировать файл» в блоке «Операции» или выберите пункт меню «Файл» → «Анонимизировать файл...».
  4. В диалоге выберите файл Три мушкетера (отрывок).docx.
  5. После обработки в той же папке появится документ с суффиксом _аноним. Откройте его и посмотрите, как были заменены имена, фамилии и другие сущности.
  6. Скопируйте текст из анонимного файла и отправьте его в ИИ-чат с кратким пояснением о значении псевдонимов (см. раздел «Оптимальные стратегии анонимизации»).
  7. Получив ответ ИИ, скопируйте его в буфер и воспользуйтесь кнопкой «Деанон буфер → буфер» или пунктом «Файл» → «Деанонизировать буфер → буфер». Результат окажется в буфере обмена.

Вариант 2. Использовать программу на своих документах

  1. Выберите или создайте файл словаря.
    Через меню «Псевдонимы» вы можете:
    • создать новый файл словаря — «Новый файл псевдонимов...»;
    • открыть существующий файл .json со словарём;
    • сохранить текущий словарь под новым именем через пункт «Сохранить файл псевдонимов как...».
    При первом запуске имеет смысл открыть готовый pseudos_base.json и при необходимости его дополнить.
  2. Добавьте нужные замены.
    В блоке «Добавление псевдонима»:
    • введите в поле «Анонимизировать» основу фамилии, имя, отчество, название организации и т.п.;
    • при желании задайте собственный псевдоним в поле «Псевдоним» (например, ФИО001); если оставить поле пустым, псевдоним будет сгенерирован автоматически.
  3. Нажмите «Добавить».
    Пара «исходный текст → псевдоним» попадёт в активный файл словаря и отобразится в списке справа.
  4. Анонимизируйте файл.
    Нажмите «Анонимизировать файл» или воспользуйтесь меню «Файл» → «Анонимизировать файл...», выберите документ .txt, .docx или .doc и дождитесь сообщения об успешном завершении.
  5. Отправьте анонимный текст в ИИ-чат.
    При формулировке запроса:
    • кратко объясните, что в тексте используются псевдонимы в квадратных скобках, которые трогать нельзя;
    • попросите сохранить окончания после скобок (например, [ФИО001]а, [ФИО001]у).
  6. Деанонимизируйте ответ.
    Возможны два варианта:
    • если у вас есть файл с анонимным текстом, используйте кнопку «Деанон файл → буфер» или пункт меню «Файл» → «Деанонимизировать файл → буфер...»;
    • если текст сейчас в буфере, нажмите «Деанон буфер → буфер» или выберите в меню «Файл» → «Деанонимизировать буфер → буфер».
    В обоих случаях результат окажется в буфере обмена, откуда его можно вставить в Word, почтовый клиент или другую программу.
