Что такое словарь псевдонимов

Словарь — это обычный JSON-файл, в котором для каждой исходной строки хранится соответствующий псевдоним. Запись имеет вид: 

{
  "Иванов": "ФИО001",
  "ООО «Ромашка»": "ОРГ001"
}

При анонимизации программа заменяет все вхождения строки Иванов на [ФИО001], а строки ООО «Ромашка» — на [ОРГ001].

Активный файл словаря

В каждый момент времени программа работает с одним активным файлом словаря. Именно в него добавляются новые записи, из него берутся замены при анонимизации и деанонимизации.

Активным считается файл, который:

  • был открыт через меню «Псевдонимы» → «Открыть файл псевдонимов...», или
  • был создан через пункт «Новый файл псевдонимов...», или
  • был получен через «Сохранить файл псевдонимов как...».

Путь к активному файлу запоминается в настройках и используется при следующих запусках программы.

Где физически лежат файлы словаря

Файл словаря может находиться в любом месте файловой системы, к которому у программы есть доступ. На практике обычно используются:

  • каталоги внутри внутренних папок рядом с программой;
  • отдельные папки по проектам или клиентам (например, _internal/pseudos/клиент_А/).

Начальная папка в диалогах открытия/сохранения выбирается так:

  • если активный файл словаря уже выбран, берётся его папка;
  • иначе — каталог, указанный в настройках (если задан);
  • иначе — папка программы.

Добавление новой пары «исходный текст → псевдоним»

  1. В блоке «Добавление псевдонима» введите в поле «Анонимизировать» текст, который нужно скрыть.
  2. При необходимости введите в поле «Псевдоним» желаемое обозначение (например, ФИО001). Если оставить поле пустым, псевдоним будет сгенерирован автоматически.
  3. Нажмите кнопку «Добавить».

После этого:

  • пара добавляется во внутренний словарь;
  • словарь сохраняется в активный JSON-файл;
  • новый ключ появляется в списке псевдонимов справа.

Обработка ошибок при добавлении

  • Ключ не введён.
    Если поле «Анонимизировать» пустое, будет показано предупреждение и запись не добавится.
  • Ключ уже существует.
    Если такой текст уже есть в словаре, программа сообщит об этом и не создаст дубликат.
  • Псевдоним не введён.
    В этом случае программа сама сгенерирует псевдоним (по умолчанию с префиксом ЗАМЕНА и трёхзначным номером).
  • Псевдоним уже используется.
    Если введённый псевдоним уже занят, программа подберёт похожий новый вариант, добавив к нему уникальный числовой суффикс.

Автоматическая генерация псевдонимов

При автогенерации псевдонимов программа ищет уже существующие значения в словаре и выбирает следующий свободный номер. Базовая схема:

  • без явного ввода используется префикс ЗАМЕНА;
  • номер оформляется как трёхзначное число: 001, 002 и т.д.

Если вы используете собственный префикс (например, ФИО, ОРГ, ДОГ), разумно придерживаться той же логики: ФИО001, ФИО002, ОРГ001 и т.д.

Сортировка и применение замен

Для анонимизации программа строит список пар исходный текст → псевдоним и сортирует его:

  • сначала по длине исходного текста (от более длинных к коротким);
  • при равной длине — в алфавитном порядке.

Это нужно, чтобы сначала заменять более длинные выражения, а затем уже более короткие фрагменты, которые могли бы входить в их состав.

Для деанонимизации наоборот строится список вида [ПСЕВДОНИМ] → исходный текст, также отсортированный по длине шаблона от длинных к коротким.

Удаление псевдонима

  1. Выберите нужный ключ в списке псевдонимов справа.
  2. Убедитесь, что в поле «Псевдоним» отображается нужное значение.
  3. Нажмите кнопку «Удалить».
  4. Подтвердите удаление в появившемся диалоге.

Пара удаляется из словаря и активного файла. После этого она больше не будет использоваться ни при анонимизации, ни при деанонимизации.

Сохранение и резервное копирование словаря

При каждом сохранении активного словаря программа создаёт резервную копию:

  • исходный файл словаря имя.json при наличии копируется в имя.json.bak в той же папке;
  • затем в имя.json записывается новое содержимое.

Это относится к любому активному файлу словаря, а не только к одному фиксированному pseudos.json.

Если при сохранении что-то пошло не так, всегда можно взять резервную копию *.json.bak и переименовать её обратно в .json.

Работа с несколькими файлами словаря

Меню «Псевдонимы» позволяет гибко работать с несколькими файлами словаря.

«Новый файл псевдонимов...»

Используйте этот пункт, когда нужно начать словарь с нуля для нового проекта или клиента:

  1. выберите пункт меню «Новый файл псевдонимов...»;
  2. укажите имя и каталог нового JSON-файла;
  3. при необходимости подтвердите перезапись существующего файла;
  4. программа очистит внутренний словарь, создаст (или перезапишет) файл и сделает его активным.

«Открыть файл псевдонимов...»

Этот пункт нужен, чтобы переключиться на уже существующий словарь:

  1. выберите «Открыть файл псевдонимов...»;
  2. найдите нужный .json-файл;
  3. после подтверждения словарь будет загружен, а список псевдонимов обновится;
  4. выбранный файл станет активным и будет использован при всех дальнейших операциях.

«Сохранить файл псевдонимов как...»

Этот пункт позволяет сделать «ответвление» словаря: сохранить текущие пары в новый файл и продолжать работу уже с ним.

  1. выберите «Сохранить файл псевдонимов как...»;
  2. укажите имя и каталог нового файла;
  3. при необходимости подтвердите перезапись;
  4. программа сохранит словарь в новый файл и сделает его активным. Все последующие изменения будут записываться туда.

Когда имеет смысл разделять словари

  • разные клиенты или доверители;
  • разные судебные дела или проекты;
  • разные типы документов (например, кадровые, договорные, процессуальные).

Раздельные словари уменьшают риск случайно деанонимизировать текст не тем набором псевдонимов.

Что делать, если словарь «пропал»

Иногда при запуске программы пользователь видит пустой список псевдонимов. Возможные причины:

  • был создан новый пустой файл словаря и сделан активным;
  • программа запомнила путь к другому файлу;
  • нужный файл был перемещён или переименован.

В таких случаях:

  1. Откройте меню «Псевдонимы» → «Открыть файл псевдонимов...» и посмотрите, какую папку программа предлагает по умолчанию.
  2. Найдите там или в соседних каталогах нужный файл словаря (.json) и откройте его.
  3. Если файл был случайно удалён или испорчен, ищите рядом резервную копию имя.json.bak: сделайте копию, переименуйте её в имя.json и затем откройте через меню.

Демонстрационные словари и базовый набор

Пример с «Тремя мушкетёрами»

Чтобы посмотреть, как программа работает «вживую», можно использовать тестовый связанный набор:

  • Три мушкетера (отрывок).docx — файл для анонимизации;
  • pseudos_three_musketeers.json — словарь псевдонимов к нему.

Откройте этот словарь через меню «Псевдонимы», затем выполните анонимизацию указанного файла — и вы увидите наглядный пример работы всех механизмов.

Базовый словарь pseudos_base.json

Файл pseudos_base.json содержит заранее подготовленные записи для наиболее распространённых русских фамилий, имён и отчеств. Его можно:

  • подключить как активный словарь;
  • при необходимости дополнить своими записями;
  • использовать как основу для «проектных» словарей через «Сохранить файл псевдонимов как...».

Это позволяет быстро начать работу, не набивая вручную десятки самых типичных ФИО.
