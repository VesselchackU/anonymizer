Режимы деанонимизации файлов

Программа выполняет обратную операцию: вместо псевдонимов вида [ПСЕВДОНИМ] подставляет исходные строки из активного словаря.

Для файлов доступны два режима:

  • Деанон файл → буфер — результат помещается в буфер обмена;
  • Деанон файл → файл — результат сохраняется в новый файл с суффиксом _деанон.

Оба режима можно запустить:

  • с помощью кнопок в блоке «Операции»;
  • через меню «Файл»:
    • «Деанонимизировать файл → буфер...»;
    • «Деанонимизировать файл → файл...».

Порядок действий

  1. Убедитесь, что активный файл словаря соответствует анонимизированному документу.
  2. Выберите нужный режим:
    • «Деанон файл → буфер», если результат нужен как обычный текст;
    • «Деанон файл → файл», если хочется получить отдельный файл с восстановленным текстом.
  3. В диалоге выбора файла укажите анонимизированный файл (.txt, .docx или .doc).
  4. Дождитесь сообщения об успешной деанонимизации.
  5. Если результат был записан в буфер обмена, вставьте его в нужную программу (Word, блокнот и т.п.).

Деанонимизация текстовых файлов (.txt)

Для файлов .txt программа:

  • читает содержимое (UTF-8, при необходимости — Windows-1251);
  • формирует список пар вида [ПСЕВДОНИМ] → исходный текст, отсортированный по длине шаблона;
  • последовательно заменяет все вхождения псевдонимов на исходные строки.

В режиме «в буфер»:

  • результирующий текст копируется в буфер обмена;
  • исходный файл не изменяется.

В режиме «в файл»:

  • результат сохраняется в новый файл .txt с суффиксом _деанон;
  • исходный файл остаётся без изменений.

Деанонимизация документов Word (.docx)

Для файлов .docx программа:

  • открывает документ как файл Word;
  • извлекает текст из основного тела документа (абзацы и таблицы);
  • извлекает текст из колонтитулов (верхних и нижних), включая таблицы;
  • применяет список замен [ПСЕВДОНИМ] → исходный текст, упорядоченный по длине.

В режиме «Деанон файл → буфер»:

  • из документа собирается единый текст с уже применёнными заменами;
  • этот текст копируется в буфер обмена;
  • сам .docx-файл не изменяется.

В режиме «Деанон файл → файл»:

  • замены выполняются непосредственно внутри документа Word: в абзацах, таблицах и колонтитулах;
  • результат сохраняется в новый файл .docx с суффиксом _деанон;
  • исходный документ остаётся без изменений.

Деанонимизация документов .doc

Для файлов .doc используется компонент textract. Программа:

  • извлекает текст из .doc;
  • применяет к нему все замены [ПСЕВДОНИМ] → исходный текст;

Далее:

  • в режиме «в буфер» результат копируется в буфер обмена;
  • в режиме «в файл» он сохраняется в текстовый файл .txt с суффиксом _деанон, а исходный .doc не трогается.

Если textract не установлен, программа сообщит об отсутствии поддержки .doc и предложит конвертировать файл в .docx.

Особенности и ограничения

  • Деанонимизация работает только с точными совпадениями вида [ПСЕВДОНИМ]. Любые изменения внутри скобок приводят к тому, что метка не будет восстановлена.
  • Если ИИ изменил псевдоним (добавил пробел, поменял регистр, удалил скобки и т.п.), такие места придётся править вручную.
  • Во всех режимах исходные файлы не изменяются: либо создаётся новый файл, либо результат кладётся в буфер обмена.
  • При большом количестве замен и длинных документах деанонимизация может занимать заметное время — интерфейс покажет «часики», а кнопки временно станут неактивными.
